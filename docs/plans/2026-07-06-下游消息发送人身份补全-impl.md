# 下游消息发送人身份补全（名字 + 头像）实施计划

> **For Claude:** REQUIRED SUB-SKILL: 用 superpowers:executing-plans 逐任务实现本计划。

**Goal:** 让下游转发的每条消息带上发送人微信名 + 头像，并顺带补齐群名/群头像，解决下游只有 wxid 无法展示发言人的问题。

**Architecture:** 正文仍走非 chatlab 的 `/api/v1/messages`；每翻一页配一次同窗口的 `chatlab=1` 请求取 `members[]`（wxid→名字+头像）与 `meta`（群名+群头像）。同步落库时按 `senderUsername` 查该页 members，把名字/头像存进 queue 新列；forwarder 拼信封时加顶层 `sender`，`data` 原样透传。群头像 upsert 进 `chat_group` 后经已有 syncGroups 推给下游。成员映射用内存、按页即用，不建成员表。

**Tech Stack:** Node.js + TypeScript（ESM）、better-sqlite3、Fastify、Vitest。**代码风格（CLAUDE.md 强约束）**：无分号、单引号；异步优先 Promise 链，`fetch→json` 顺序依赖可用 async/await。每任务完成跑 `npm run lint`。

> 设计依据：[2026-07-06-下游消息发送人身份补全-design.md](2026-07-06-下游消息发送人身份补全-design.md)
> 分支：直接在当前 `rewrite/v2` 上实现（不开 worktree）。
> 单文件测试：`npm -w server exec -- vitest run <相对 server 的路径>`；全量：`npm test`（或 `rtk vitest`）。

```typescript
    /**
     * 取会话成员身份映射（chatlab 模式）。仅解析 meta（群名/群头像）与 members（wxid→名字/头像），
     * 忽略 chatlab 精简过的 messages（缺关键字段，不可当正文用）。窗口参数须与正文页同窗口，
     * 保证该页发送人都在 members 里。缺字段一律降级 null / 空映射。
     */
    async fetchMembers(talker: string, start: number, offset: number, limit = 1_000, end?: number): Promise<MembersResult> {
        const params: Record<string, string | number> = { talker, offset, limit, chatlab: 1 }
        if (start > 0) params.start = start
        if (end !== undefined && end > 0) params.end = end
        const data = await this.getJson('/api/v1/messages', params) as {
            meta?: { name?: string, groupAvatar?: string }
            members?: Array<{ platformId?: string, accountName?: string, avatar?: string }>
        }
        const members = new Map<string, MemberInfo>()
        for (const m of Array.isArray(data.members) ? data.members : []) {
            if (typeof m.platformId === 'string' && m.platformId) {
                members.set(m.platformId, { name: m.accountName ?? null, avatar: m.avatar ?? null })
            }
        }
        return {
            groupName: data.meta?.name ?? null,
            groupAvatar: data.meta?.groupAvatar ?? null,
            members,
        }
    }
```
